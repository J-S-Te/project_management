## 1. 转换说明与粒度约定

- **模块**：对应 PRD 第 5 节功能域（FR-PJ-1xx / 2xx / 3xx）+ 看板 + 配置。
- **页面类型**：列表页 / 详情页(Tab) / 表单页 / 确认页 / 审批页 / 看板 / 配置页 / 移动页 / 抽屉(Drawer) / 弹窗(Dialog)。
- **访问角色**：依据 PRD 第 3 节角色职责与第 6 节字段级权限推导。
- **复用组件**：优先使用 UI 规范既有组件（`SearchBar` / `StatCard` / `ApprovalFlow` / `crm-card` / `crm-table-wrap` / `crm-badge` / `el-button` / `el-pagination` / `el-drawer` / `el-dialog`）；无对应组件时标注「需新增」并说明形态。
- **优先级**：P0=本期必须；P1=重要（可 fast-follow）；与 PRD FR 优先级对齐。

## 5. 关键页面要素说明

以下对 6 个核心页面给出区块、字段、操作与校验，供 UI 设计与前端直接落地。

### 5.1 PG-PRJ-03 服务项拆解确认页（待确认）— FR-PJ-101/103

- **布局**：左树（批次→检测类别）右明细；顶部合同信息卡（`crm-card`）。
- **区块**：
  - 合同来源卡：合同编号、客户、生效日期、服务清单引用。
  - 服务项树/矩阵：自动生成的服务项（批次/检测类别/系统名称/技术要求摘要/来源条款）；**技术要求摘要字段默认可编辑**；系统名称若合同信息中未提供则自动填写「/」。
  - 勾对区：按合同服务清单逐项标记「已拆解 / 未拆解 / 超范围」（`crm-badge`）。
- **操作**：`确认拆解`(primary) → 状态 待确认→待分配；`调整`(secondary) → 打开 PG-PRJ-04；`导出`(Download)。
- **校验**：分组规则缺失时服务项标「待人工确认」并通知业务管理员（PRD FR-PJ-101 验收 3）；确认前不可进入分配。
- **状态**：整页仅对「待确认」服务项开放。

### 5.2 PG-RES-03 项目经理/工程师指派抽屉 — FR-PJ-202

- **形态**：`el-drawer` 右侧滑出，支持批量选中服务项。
- **字段**：项目经理（必选）、实施工程师（可多人）、计划开始/结束日期。
- **内嵌 PG-RES-07 冲突预警**：保存时实时校验资质/设备/人员时间窗冲突（`crm-badge` 阻断/警告）；阻断需上级审批留痕方可强制通过。
- **操作**：`保存`(primary) → 状态 待分配→待实施，相关人收待办；`套用模板`(secondary) 复用同类服务项人员/计划。
- **校验**：计划日期不得早于合同交付下限（可配置规则）。

### 5.3 PG-RES-04 现场实施计划制定页 — FR-PJ-203

- **布局**：`crm-card` 分区——基础信息 / 人员设备 / 行程 / 渗透测试计划（条件显示）。
- **字段**：时间、路线、实施工程师、设备、行程（地点/人员/时间）。
- **条件分支**：检测类别=渗透测试 时，强制显示「渗透测试计划」子表（授权边界/范围/时间窗），未填不可发起实施。
- **操作**：`保存草稿` / `发起实施`(primary)。

### 5.4 PG-IMP-06 异常评审页 — FR-PJ-304

- **布局**：上 `ApprovalFlow` 展示异常上报→评审；下评审表单。
- **字段（只读）**：异常类型、描述、证据（照片/文件）。
- **评审操作**：`放行`(Check/success) / `重测`(warning) / `终止`(Close/danger)。
  - 放行/重测 → 回到实施中。
  - 终止 → 弹出 `el-dialog` 必填终止原因，联动合同补充协议/结算待办（PRD FR-PJ-304）。
- **留痕**：评审结论、评审人、时间全记录（满足 ISO 27001 记录控制）。

### 5.5 PG-DASH-01 项目执行总览看板 — 第10节

- **StatCard 行（4 列，`stat-row` grid）**：
  - 现场实施准时交付率（北极星，`trend` 对比基线 [待基线]）
  - 合同→项目拆解自动化率（≥90%）
  - 资源下达及时率（≥95%）
  - 异常闭环时长（≤1 工作日）
- **下方区块（`dashboard-grid` 2:1）**：
  - 左：服务项状态分布表（`crm-table-wrap` + `crm-badge` 按 2.2 映射）+ 进度回传准确率（100%）。
  - 右：超期/风险提醒卡（资质冲突拦截数、离线提交成功率）。
- **下钻**：点击 StatCard / 状态行 → 跳转 PG-PRJ-01 带筛选。

### 5.6 PG-IMP-10 报告编制状态维护页 — 状态机 4.1/4.2

- **说明**：本子系统拥有「报告编制 / 整改中」状态（PRD 修订确认）。页面供项目经理维护该阶段状态流转。
- **操作**：
  - `发起报告审核`(primary) → 状态 报告编制→报告编制已完成（下游主导）。
  - `变更为整改中`(warning) → 弹出 `el-dialog` **必选变更原因**（原因分类 + 说明），状态 报告编制⇄整改中。
  - 原因解决后 `回到报告编制`(primary)。
- **只读呈现**：报告编制已完成 / 审核已通过 / 已归档 由下游回传独立字段，本页仅展示不可编辑（`crm-badge` 对应 2.2）。
